# Employee-Management-System
Employee management and leave tracking system.  
A web-based Employee Leave Management System that helps organizations manage employees, leave requests, approvals, and leave records in one place.

## Features

- User login and authentication
- Employee management
- Create and manage leave requests
- Approve or reject leave requests
- Track employee leave balances
- View employee profiles
- Leave reports
- Dashboard with leave statistics
- Role-based access for administrators and managers

## Technologies Used

### Frontend
- React.js
- React Router
- CSS
- Axios

### Backend
- Node.js
- Express.js
- JWT Authentication
- Express Validator

### Database
- MySQL
